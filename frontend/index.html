Export a backup of all system data (students, fees, salaries, settings, users) as a JSON file, or restore from a previously exported file.

Danger Zone

Resets institution info, late fee % / due day, and security settings back to system defaults. Program fee amounts, students, fees, salaries, and other records are not affected.
